# crypto-crash-playbook

简体中文 | [English](README_EN.md)

一个可复用的 WorkBuddy Skill：把**任何一次极端加密资产 / 高Beta风险资产冲击**，转化为
(1) 经过事实核查的因果链复盘，与 (2) 可直接执行的交易风控 SOP。

核心立场：**不预测方向，只做预案**——价值落在「杠杆纪律」+「交易所基础设施风险对冲」上，
而不是涨跌判断。

---

## 包含内容

| 文件 | 作用 |
|---|---|

| `references/technical_factors.md` | 已核实的机制定义（ADL、预言机/幻影价格、资金费率、稳定币脱锚、跨所传染）+ 2025-10-10 事件细节 |
| `references/data_sources.md` | 预警仪表盘每一项指标对应的实时免费数据源清单（取数清单） |

| `crypto-crash-playbook.zip` | 已打包的 Skill，可一键安装 |

## 安装

**方式 A（源码）**：把本目录整体复制到
`~/.workbuddy/skills/crypto-crash-playbook/`

**方式 B（zip）**：解压 `crypto-crash-playbook.zip` 到
`~/.workbuddy/skills/`

## 内置案例

以 **2025-10-10 BTC 闪崩**（3 小时 $123K→$102K、爆仓 $19.3B、87% 为多头）作为工作范例，
完整覆盖：宏观政策催化（关税）→ 中心化交易所基础设施异常（预言机 / ADL，属放大器而非起源）→ 做市商撤离流动性
→ 多头踩踏 → 散户归零 / 巨鲸获利。详见 SKILL.md 与各交付物引用。

## 用法

下次再遇到任何极端行情（崩盘 / 巨量爆仓 / 宏观黑天鹅），直接说：
> 「按 crypto-crash-playbook 复盘 + 出策略」

即可复用整条工作流。
